Why it's built this way

The worst failure mode of a
transcoder is lying to you

It finishes, it looks successful, and the file is broken. So every output is read back and checked. Ten milliseconds is cheap insurance.

🔍

Probe before converting

No duration or sample rate means no conversion. Empty files, random bytes and text files renamed .mp3 are rejected with a stated reason, not silently skipped.

♻️

Sources are read-only

Output always lands in a separate folder. Same names get numbered: song.mp3, song (2).mp3, song (3).mp3. There is no overwrite option, and there never will be.

✅

Verified round-trip

After each conversion the output is re-read with ffprobe and checked for codec, duration and lossless-ness. The self-test transcodes all seven formats for real.

🧹

Clean failure

Output is written to .part and only renamed on success. A failed run leaves nothing behind — no half-written file, no stray temp files.

⏭️

Skips pointless work

Lossless to lossless is skipped with a reason: turning FLAC into WAV just swaps the container and doubles the size.

🌐

Bilingual & themed

Chinese and English, switchable top-right. Six themes, all checked against WCAG AA. Fully offline — no network calls, ever.

Seven targets

Pick a format, pick a bitrate

Input containers are unrestricted — anything ffprobe recognises works (FLAC / WAV / AIFF / M4A / MP3 / AAC / Opus / OGG / WMA / APE / WavPack …).

Safety

What it refuses to do

A converter is only trustworthy if you're willing to run it on files you care about.

  • ✓
    Sources are never written to Output goes through a numbering helper into a separate folder. No code path overwrites an input.
  • ✓
    Failed runs leave nothing The .part file is removed on failure, so there's never a truncated output masquerading as a real one.
  • ✓
    Blind conversions are refused If ffprobe can't read the duration, the file is reported, not guessed at.
  • ✕
    No "delete source" feature Not now, not later, not on request.
  • ✕
    No bundled codecs ffmpeg is yours to install. It isn't redistributed, so its size and licence compliance aren't this project's problem.
  • ✕
    No network, no telemetry Runs fully offline. Nothing about your files or your machine leaves it.
