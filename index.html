Why it's built this way

The worst failure mode of a
transcoder is lying to you

It finishes, it looks successful, and the file is broken. So every output is read back and checked. Ten milliseconds is cheap insurance.

🔍

Probe before converting

No duration or sample rate means no conversion. Empty files, random bytes and text files renamed .mp3 are rejected with a stated reason.

♻️

Sources are read-only

Output always lands in a separate folder. Same names get numbered: song.mp3, song (2).mp3. There is no overwrite option, and there never will be.

✅

Verified round-trip

After each conversion the output is re-read with ffprobe and checked for codec, duration and lossless-ness. The self-test transcodes all seven formats for real.

🧹

Clean failure

Output is written to .part and only renamed on success. A failed run leaves nothing behind — no half-written file.

⏭️

Skips pointless work

Lossless to lossless is skipped with a reason: turning FLAC into WAV just swaps the container and doubles the size.

🔐

DRM: honest, not sneaky

KGM / VPR / QMC / NCM are recognised and grouped as unplayable. Calling them "damaged" would be a lie — the file is fine, it has DRM on it.

Batch audit

How much of this pile
is actually junk?

Drop a folder in — it recurses the whole tree — or run AudioForge.exe --audit D:\Music.

  • ✓
    Convertible Real audio, with codec, sample rate, channels and duration read from the file.
  • ✕
    DRM-encrypted KGM / VPR / QMC / NCM. The file is intact — it just can't be played without the provider's app. Nothing is unpacked.
  • ✕
    Damaged / not audio Truncated FLAC, empty files, a text file renamed .mp3. Each with the specific reason.
  • ✕
    No "delete source" feature Not now, not later, not on request.
  • ✕
    No bundled codecs ffmpeg is yours to install. It isn't redistributed.
  • ✕
    No network, no telemetry Runs fully offline. Nothing about your files leaves it.
